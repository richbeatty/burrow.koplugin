BURROW LEGACY FILE CLEANUP

Before using Burrow, disable or remove these standalone plugins when present:

plugins/projecttitle.koplugin
plugins/opds_plus.koplugin
plugins/opdsplus.koplugin

Burrow requires KOReader's built-in Cover Browser plugin to be disabled.

When upgrading from Burrow 0.1.x, remove:

patches/2-burrow-bootstrap.lua

Also remove older loose Burrow or ProjectTitle patches that duplicate features now included inside Burrow, especially patches for:

- automatic series folders
- browser folder covers
- rounded or stretched covers
- percentage badges
- series badges and indicators
- Home and Store footer tabs
- ProjectTitle top-bar or hero-card changes
- cover gap, cover size, or 8 by 8 grid controls
- rounded Quick Settings or reader menus
- status-bar margin and preset controls

Do not delete these legacy settings files until Burrow has migrated successfully and the library and Store have been verified:

settings/PT_bookinfo_cache.sqlite3
settings/opdsplus.lua

Burrow copies compatible data into:

settings/burrow_library.sqlite3
settings/burrow_store.lua

The legacy source files are left untouched as backups.
